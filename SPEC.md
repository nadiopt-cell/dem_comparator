# DEM Comparator — QGIS Plugin Specification

**Цель плагина:**  
Дать пользователю возможность быстро скачать несколько глобальных ЦМР (DEM) на одну и ту же территорию, выровнять их на единую сетку и сравнить между собой, чтобы выбрать наиболее подходящий/точный источник для своей задачи.

**Тип плагина:**  
Отдельный плагин (не расширение Isoliner).  
Интерфейс: диалог + опционально Processing-алгоритмы.

**Целевая аудитория:**  
Геологи, гидрологи, картографы, специалисты по моделированию рельефа, пользователи Isoliner.

---

## 1. Основной пользовательский сценарий (MVP)

1. Пользователь открывает плагин.
2. Задаёт территорию одним из способов:
   - Текущий вид карты (canvas extent)
   - Выбранный векторный слой (extent слоя)
   - Нарисовать прямоугольник на карте
3. Выбирает источники DEM галочками (минимум 4–5 источников).
4. Нажимает «Скачать и сравнить».
5. Плагин в фоне:
   - Скачивает выбранные DEM
   - Обрезает по extent
   - Приводит все растры к единой сетке (CRS, resolution, extent)
   - Считает попарные разницы и статистику
6. Результаты автоматически добавляются в проект:
   - Исходные (обрезанные и выровненные) DEM
   - Растры разницы
   - Таблица/отчёт со статистикой
7. Пользователь анализирует результаты и выбирает лучший DEM для дальнейшей работы.

## 3. Функциональные требования

### 3.1. Выбор территории
- Canvas extent
- Extent выбранного векторного слоя
- Инструмент рисования прямоугольника (rubber band)
- Возможность вручную ввести координаты (опционально)

### 3.2. Загрузка
- Параллельная загрузка выбранных источников
- Прогресс-бар + возможность отмены
- Кэширование скачанных тайлов (простая папка кэша)
- Корректная обработка ошибок сети и отсутствия данных

### 3.3. Выравнивание растров
Все растры должны быть приведены к:
- Одному CRS (предпочтительно исходный CRS территории или EPSG:4326 / UTM)
- Одинаковому spatial resolution
- Одинаковому extent (с небольшим буфером при необходимости)
- Одинаковому размеру пикселя и origin

Метод ресемплинга по умолчанию: **bilinear** (с возможностью выбора cubic).

### 3.4. Сравнение
Для каждой пары DEM (или относительно выбранного эталона):

**Растр разницы:**
- `DEM_A - DEM_B`
- Понятная цветовая шкала (синий = отрицательные, красный = положительные)

**Статистика (только по валидным пикселям):**
- Mean Bias
- MAE (Mean Absolute Error)
- RMSE
- Std. Dev.
- Min / Max разницы
- Количество валидных пикселей

### 3.5. Результаты в проекте
Автоматически добавлять слои с понятными именами:
- `DEM_FABDEM_aligned`
- `DEM_GLO30_aligned`
- `DIFF_FABDEM_minus_GLO30`
- и т.д.

Группировать слои в группу «DEM Comparator Results».

### 3.6. Отчёт
Генерировать HTML-отчёт (или Markdown), который содержит:
- Параметры запуска (extent, выбранные источники, resolution)
- Таблицу статистики по всем парам
- Краткие выводы (какой DEM ближе к какому)

Отчёт сохранять рядом с результатами и открывать по кнопке.

## 4. Технические требования

### 4.1. Зависимости
- Только стандартные библиотеки QGIS + GDAL + NumPy
- Внешние pip-пакеты **не использовать** в MVP (максимальная совместимость)

### 4.2. Многопоточность
- Все долгие операции выполнять через `QgsTask` или `QgsProcessingFeedback`
- UI не должен зависать
